# 自定义 AI 服务与首页工具卡片

在「设置 → AI 服务」选择「自定义 OpenAI 兼容服务」，填写接口**根地址**，例如 `http://127.0.0.1:5001/v1`。程序向其追加 `/models` 获取模型列表，向 `/chat/completions` 发起翻译；末尾的 `/` 会自动处理。支持 `http` 本机服务和 `https` 代理/反代。地址不能包含查询参数或片段。

自定义服务的 API Key 可留空；填写后会发送 `Authorization: Bearer ...`。预设服务仍需 Key。模型可以直接在可编辑下拉框中输入；若接口不提供 `/models`，在「手动模型列表」用逗号分隔模型 ID，随后从下拉框选择。设置仍保存在原有 `settings.json` 中；切换服务商时，当前会话内的地址、Key 和模型输入会保留。

首页从纵向工具设置行改为工具卡片网格。每个工具由 `ToolDefinition` 提供标题、简介和悬浮说明，新增工具时复用同一展示方式。窗口宽度决定列数；卡片可以点击，也可以用键盘聚焦后回车打开。截图与设置是独立的紧凑快捷操作，不再占据整行宽度。

本地回归使用模拟 HTTP 服务验证空 Key 请求不携带认证头、末尾斜杠生成正确路径、模型列表响应、自定义设置保存及切换服务商保留输入。静态构建完整回归已通过。
