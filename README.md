# SnapLens

> 一键截图 · 即时识别 · AI 翻译 —— Windows 桌面的轻量工具箱

SnapLens 把截屏、取色、钉图、文字识别和 AI 翻译装进一个窗口。按下快捷键框选屏幕，就能直接复制、保存、贴图，或把内容交给 OCR 与 AI。

整个程序打包为单个 EXE，开箱即用：无需额外安装运行库，Qt 与 OCR 引擎均已内置。

---

## 主要功能

### 截图

- **全局快捷键**：默认 `Ctrl+Shift+Z`，可在设置中改成任何顺手的组合
- **框选**：按住左键拖动框选任意区域
- **窗口点选**：单击自动吸附到窗口边界，在空白处单击则选整个屏幕
- **多屏支持**：每个显示器独立覆盖，混合 DPI 缩放下坐标依然准确
- **随时取消**：`Esc` 放弃本次截图，`双击` 或 `Enter` 直接复制并退出

### 十字准星与实时信息

截图时屏幕上贯穿一条十字辅助线，光标附近实时显示**当前坐标**与**光标下的像素颜色**。颜色标签支持 RGB 与 Hex 两种格式，按 `Shift` 即可切换；按 `C` 把颜色复制到剪贴板。

### 像素放大镜

光标周围跟随一枚放大镜，逐像素看清画面细节，方便选边界或取色：

- 倍率 **4.0× ~ 20.0×**，滚动滚轮实时缩放，带平滑过渡
- 可选显示像素网格、放大镜十字线，以及屏幕边缘的填充策略
- 支持方向键、WASD 或两者微调准星，每次移动一个物理像素（长按不连发），便于精确定位

以上十字准星、各类标签、网格与放大镜外观，都能在设置里逐项开关与调色。

### 截图结果操作

框选完成后，工具栏提供这些动作：

| 按钮 | 操作 |
|------|------|
| 保存 | 存为 PNG / JPG / BMP，目录与格式可配置 |
| 钉图 | 生成一个置顶小窗，随手参考 |
| OCR | 就地识别文字，支持多语言 |
| AI 翻译 | 把识别结果交给 AI 翻译 |
| 确认 | 复制到剪贴板并结束 |

### 钉图

把任意截图钉在屏幕上：无边框置顶窗口，可自由拖动，滚轮缩放（0.05× ~ 10×），右键复制、另存为或关闭。可以同时钉多张图。

### OCR 文字识别

- 内置 Tesseract 5.5 引擎，进程内运行，直接读取截图，无需额外安装
- 支持中英日韩等多语言，可同时识别多种语言
- 语言包可在「设置 → OCR 识别」中在线下载，随用随取

### AI 翻译

翻译支持两种入口，共用同一套 AI 服务配置：

- **截图翻译**：框选区域 → OCR 提取文字 → AI 翻译 → 在窗口中同时查看**原文**、**译文**与**AI 思考过程**
- **文本翻译**：直接输入或粘贴文本翻译，可选择**通用 / IT / 医学 / 金融 / 法律 / 学术 / 文学**等专业场景

其他特性：

- **流式输出**：译文逐字实时显示，无需等待整段生成
- **多服务商支持**：内置 DeepSeek、OpenAI、通义千问、Kimi、智谱 GLM、腾讯混元、豆包、文心一言等预设服务商
- **自定义服务**：可接入任意 OpenAI 兼容接口，填写本机、代理或反代的接口地址即可；自定义服务允许不填 Key，也能手动维护模型列表
- **模型列表**：可从服务商一键拉取候选模型（异步获取，不卡界面），也可手动输入
- **参数按服务商适配**：温度、Top P、惩罚项、采样开关（GLM `do_sample`）、随机种子、停止序列、输出上限、思考模式与推理强度均可调；各服务商设 `temperature`/`top_p` 上限、固定或废弃的字段会按官方文档自动裁剪或隐藏，不会把参数送到不支持它的接口上
- **输出与停止**：输出上限字段名随服务商切换（Kimi 用 `max_completion_tokens`，其余多为 `max_tokens`），上限值按服务商放开；停止序列每行一条
- **思考与推理**：支持 DeepSeek / GLM / Kimi 的思考开关与推理强度、通义千问的 `enable_thinking`，以及豆包的 `thinking` + `reasoning_effort`；强制思考的模型会禁用关闭选项
- **提示词可定制**：截图翻译与文本翻译的提示词模板都能自行修改
- **配置校验**：Key、模型或地址未填时会提前拦截，并给出明确提示，不会白跑一次请求

各服务商支持哪些字段、取值范围与依据，见 [AI 参数与服务商适配](docs/ai-parameters.md)。

翻译进行中可以随时关闭窗口，请求会立即中断，不浪费额度。

### 界面与体验

- 工具箱式布局：首页以卡片形式展示各功能，左侧导航直达
- 设置集中在窗口内，按「应用 / 共享服务 / 截图 / 翻译」分组，含分类搜索
- 跟随系统的深浅色主题，也可手动固定为浅色或深色
- 常驻系统托盘，关闭主窗口可选择询问、后台运行或直接退出
- 完整的系统通知：复制、保存、翻译成功/失败、快捷键注册等事件均可单独开关

### 日志

内置统一日志，时间、线程与级别一并记录。可在「设置 → 常规」中按 DEBUG / INFO / WARNING / ERROR 四级分别开关。日志默认写入 `%LOCALAPPDATA%/SnapLens/logs/snaplens.log`，单文件上限 5 MiB，自动保留 3 个历史文件。

## 上手

1. 运行 `SnapLens.exe`，默认打开工具箱首页
2. 按 `Ctrl+Shift+Z`（或点击「开始截图」）开始截图
3. 要使用 AI 翻译，先在「设置 → AI 服务」选择服务商，填入 API Key 与模型
4. 要使用 OCR，确认所需语言包已在「设置 → OCR 识别」中安装

首次启动即为默认配置，AI 与 OCR 相关设置在使用对应功能时按需配置即可；OCR 与 AI 未就绪时会自动引导到相应设置页，配置完成后可继续处理刚才的截图。

配置文件保存在程序目录下的 `settings.json`（也可在设置中指定其他位置）。

## 已知说明

- 翻译窗口与 OCR 窗口为单实例，再次触发会替换旧窗口；钉图支持多张并存
- 系统托盘不可用时，「后台运行」会自动回退为打开工具箱
- 多屏选区不能跨屏拖拽
- 退出时 Tesseract 偶尔打印 `ObjectCache LEAK` 警告，属其库自身的静态析构行为，并非真实泄漏（进程退出码仍为 0）
